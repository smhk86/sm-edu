# SM EDUCATION v2.8.0 — Release report

## Scope
Stepwise STEM solution review and geometry-aware formative feedback, built on v2.7.0.

## Delivered
- Added a dedicated student solution-steps field (up to 5,000 characters).
- Added an optional geometry/diagram description field (up to 2,500 characters).
- Updated the smart-teacher correction prompt to inspect intermediate calculations, substitutions, transformations, units, signs, symbols, reasoning order, and final answers.
- Requires the tutor to identify the first algebraic error and explain a correction.
- For geometry, uses only stated givens and the learner's description; it must not assume unsupported parallel, perpendicular, equal-length, or angle relationships.
- Maintains question-by-question formative marking, an explicitly non-official estimated score, and three targeted remedial exercises with separate solutions.
- Updated frontend, API, service-worker cache, package metadata, and regression tests.

## Limitations
- This release does not implement full automatic visual understanding of diagrams or handwriting. The learner should describe the figure; unclear symbols require a clearer image.
- AI feedback requires the configured Groq capability and network access. No production provider key was used in tests.
- No Android APK build or physical-device test was performed.
