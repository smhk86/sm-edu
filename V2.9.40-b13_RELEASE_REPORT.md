# SM EDUCATION v2.9.40-b13 Release Report

## Scope
This maintenance release fixes a retrieval-context mismatch in the Smart Teacher Gemini grounding path. The initial retrieval respected the selected subject, but the second retrieval used to build `kb_context` did not receive the request's selected grade and subject. The grounding query now receives both fields, preserving the learner's context through to the AI prompt.

## Changes
- `web/smart-teacher-core.js`: `kbContextSync` accepts scope options and applies grade/subject during retrieval; the API interception passes the request grade and subject.
- `tests/v2_9_40_smart_teacher_core_test.js`: regression coverage for the same topic across primary and middle-school subject contexts.
- `web/sw.js`: shell cache revision incremented from b12 to b13.

## Validation
Targeted Smart Teacher core test and syntax validation are required before packaging. This release does not change the application semantic version (2.9.40), does not build an APK, and does not claim a physical Android-device test.
