# SM EDUCATION v2.9.36 — Textbook Knowledge Expansion

Base: v2.9.35

## Delivered
- Expanded the textbook library workflow for all currently supported school grades and subjects.
- Imported PDFs are stored locally in IndexedDB with the original PDF blob and extracted page-by-page text.
- Added an internal full-screen PDF reader with page/text modes and in-app download.
- Added local keyword search over indexed textbook pages, returning book title, grade, subject, page number and excerpt.
- Added a consent-gated teacher context API that can return the top matching page excerpts with source metadata.
- Increased extraction coverage from the former first-18-pages limit to all PDF pages, up to a 1.2M-character safety cap per book.
- Legacy records remain readable; records without a stored PDF prompt the user to re-import the source file.

## Important limits
- ONPS remains the official discovery portal; no unverified PDF URLs are fabricated.
- Scanned/image-only PDFs require OCR before their content can be searched.
- Imported files and indexes are local to the device/browser profile. They are not automatically synchronized across devices.
- The AI provider receives excerpts only after the user enables the explicit consent checkbox.
