# SM EDUCATION v2.8.2 — exam generator and visual maths quality

## Scope
This release builds on v2.8.1 and focuses on two connected areas: strengthening visual-math review safeguards and improving the term-exam generator.

## Exam generator
- Supports first, second and third term selection through the existing exact-match grade/subject/term workflow.
- Adds requested difficulty (mixed/easy/medium/hard), duration (15–240 minutes API range; UI presets 30/60/90/120), and total marks (10–40 API range; UI presets 10/20/30/40).
- Produces separate student and teacher versions.
- Teacher copy includes model answers, worked solution steps and question-level marking criteria.
- Recent question IDs are stored locally per grade/subject/term and excluded when enough exact-match alternatives remain.
- Selection never substitutes another grade, subject, term or language. If the exact-match pool is insufficient, the endpoint reports that rather than inventing questions.

## Curriculum and quality safeguards
- Papers are platform practice material, not official Ministry examinations.
- Exact annual lesson progression and some secondary stream mappings remain unverified; teacher review is required.
- Difficulty is filtered when the exact-match bank contains enough items; otherwise the generator keeps exact-match questions and does not claim the requested difficulty was fully achieved.
- Visual diagrams are interpreted by the existing multimodal teacher flow; unclear values and relationships must remain marked uncertain, not guessed.

## Verification
- Full `npm test` suite.
- Python compile checks and JavaScript syntax checks.
- Curriculum audit: 105 grade/subject records, 1,581 exercise records, zero errors and zero warnings.

## Limitations
No APK build, production Groq request, or physical Android device test was performed in this release environment. Question generation uses the curated platform exercise bank; it does not invent new officially aligned source questions when the exact pool is insufficient.
