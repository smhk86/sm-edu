# SM éducation v2.9.40 — build b11

## Scope
Focused hardening of the Vision OCR textbook import path. This build keeps the application/package/API version at `2.9.40`; `b11` is the service-worker shell build revision, not a new semantic application version.

## Changes
- Compressed file limit: 64 MiB.
- Decompressed text limit: 128 MiB, enforced while streaming gzip decompression.
- Strict UTF-8 decoding and malformed JSON handling.
- Maximum 1,000 books per import and 3,000 page entries per book.
- Duplicate page numbers are collapsed, retaining the longest usable text.
- Duplicate book IDs in one import are collapsed, retaining the version with the greatest number of indexed pages.
- Existing saved books are not downgraded by a smaller re-import.
- Vision import regression test is now part of `npm test`.
- Service worker cache revision advanced to `sm-school-ai-v2.9.40-shell-r2-b11`.
