# SM Education v2.9.21 — Adaptive Smart Teacher

## Changes
- Smart Teacher now prefers the curated exercise bank only for an exact learner grade and selected subject; it falls back to the existing practice pool when no suitable curated items exist.
- Session difficulty is based on the learner’s own recorded answers from the last 30 days. Fewer than five answers triggers a neutral discovery session instead of assuming a weak level.
- Repeated, learner-scoped topic mistakes receive priority when selecting tagged questions.
- A learning-memory snapshot is refreshed after a Smart Teacher assessment is saved.
- Release metadata, service-worker cache and package/API versions updated to 2.9.21.
