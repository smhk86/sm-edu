# SM éducation v2.9.19

## v2.9.16 — تطوير التصحيح التفصيلي خطوة بخطوة
- تطوير محرك التصحيح الموجود داخل فضاء المعلم الذكي؛ لا توجد أداة تصحيح ثانية.
- تقسيم كل سؤال إلى معايير وخطوات تصحيح مع نقاط قصوى ونقاط ممنوحة ودليل من إجابة التلميذ وتعليل تربوي.
- تحديد أول خطأ وموضعه وتصنيفه (مفهومي، منهجي، حسابي، إشارة، وحدة، ترميز أو لغة) مع إظهار التصحيح.
- تطبيع مجموع نقاط المعايير ليتطابق مع نقاط السؤال، وحساب العلامة برمجياً بدلاً من الوثوق بمجموع النموذج.
- الحفاظ على حالتي «بلا إجابة» و«غير مقروء» وعدم منحهما نقاطاً، مع طلب مراجعة الأستاذ عند انخفاض الثقة أو وجود أجزاء غير واضحة.
- إبقاء موافقة الإرسال الصريحة إلى Groq، وعدم حفظ الصور، وعدم إرسال اسم التلميذ، وعدم اعتبار العلامة رسمية.
- الحفاظ على واجهات الخادم ومسارات API الحالية.


## v2.9.15 — توحيد المولّد الذكي وتوسيع إنشاء المسودات
- دمج إنشاء المسودات الأصلية عبر Claude داخل صفحة المولّد الذكي الحالية، وإزالة بطاقة Claude المنفصلة من صفحة بنك الاختبارات.
- إعادة استخدام اختيارات الطور والمادة والفصل والصعوبة والعدد والمدة والعلامة نفسها عند توليد المسودة.
- إضافة التحقق من وجود خطوات حل لكل سؤال، وفحص مجموع شبكة التنقيط مقابل العلامة المطلوبة.
- عرض الوضعية الإدماجية والحلول وشبكة التقييم داخل معاينة المولّد، مع حفظ محلي اختياري للموضوع فقط.
- استمرار منع النشر التلقائي في بنك التمارين والحفاظ على حماية واجهة Claude برمز الأستاذ/الإدارة ومفتاح الخادم.


- إضافة تحقق بنيوي لمسودات Claude قبل عرضها: عدد الأسئلة، نص السؤال، الإجابة النموذجية وخطوات الحل.
- التحقق من وجود سياق واضح للوضعية الإدماجية.
- إظهار معاينة تعليمية منظمة مع حالة التحقق وسلم التنقيط.
- منع النشر التلقائي؛ تبقى جميع المسودات قيد مراجعة الأستاذ، ولا تُعد مواءمتها الرسمية مثبتة.



## v2.9.13 — تحسين مستويات الصعوبة وسلم التنقيط

- توحيد مستويات الصعوبة بين التسميات العربية والفرنسية والإنجليزية؛ مبتدئ/سهل = easy، متوسط = medium، متقدم/صعب = hard.
- إصلاح تصفية الأسئلة حسب الصعوبة وإحصاء توزيعها في ورقة الاختبار.
- إنشاء سلم تنقيط مفصل من خطوات الحل المتاحة، مع توزيع النقاط بأجزاء المئة وضمان تطابق مجموعها مع نقاط السؤال.
- الإبقاء على مراجعة الأستاذ وعدم الادعاء بأن التصنيف أو سلم التنقيط اعتماد رسمي من الوزارة.

## v2.9.12 — تحسين توازن وجودة الاختبارات المولّدة

- اختيار الأسئلة بالتناوب بين المواضيع والعمليات المعرفية لتقليل التكرار وزيادة التغطية.
- استبعاد المعرفات المكررة والأسئلة التي لا تحتوي على إجابة قابلة للتصحيح.
- إضافة تقرير جودة مضمّن في بيانات الاختبار يوضح سلامة المعرفات والإجابات وعدد الأسئلة.
- الحفاظ على التطابق الدقيق للسنة والمادة والفصل واللغة، ومنع الاستبدال الصامت من مستوى آخر.
- تحديث إصدار الواجهة وواجهة API والخدمة دون تغيير مسارات API أو تعطيل وظائف الخادم.

## v2.9.11 — موثوقية تحليل PDF المصوّر
- تحسين مسار OCR لملفات PDF المصوّرة مع استمرار التحليل البصري عند تعذر OCR.
- توحيد اختبارات الواجهة والتنقل مع المتطلبات الحالية، مع إبقاء إصدار API الخلفي مستقلاً عند v2.9.10.

## v2.9.10 — تحليل الملفات واستخراج التمارين وحلها
- إضافة وضع استخراج مستقل للأسئلة والمعطيات من الصور وملفات PDF وDOCX، دون اشتراط إدخال إجابة التلميذ.
- إضافة وضع حل التمرين خطوة بخطوة، مع شرح القواعد والقوانين والحساب والوحدات.
- الإبقاء على وضع تصحيح إجابة التلميذ وشرح الأخطاء، مع جعل الإجابة مطلوبة في هذا الوضع فقط.
- احترام حدود القراءة البصرية: عدم تخمين الرموز أو القياسات غير الواضحة، والتنبيه إلى الحاجة لصورة أوضح.
- الحفاظ على OCR ومسارات PDF النصية والمصوّرة ومكتبات DzExams وRaji3DZ.

- لا تُحسم التعارضات آلياً ولا تُستنتج القياسات من شكل الرسم.
