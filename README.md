## التشغيل
- `npm test` — مجموعة الاختبارات والتحقق من سلامة المحتوى.
- `npm run serve` — تشغيل واجهة الويب محلياً على المنفذ 8080.
- `npm run android:sync` — مزامنة موارد Capacitor إلى مشروع Android بعد تثبيت الاعتماديات.
- `npm run android:build:debug` — بناء APK تجريبي عند توفر Android SDK وGradle wrapper.

## حدود التحقق
اجتياز الاختبارات الآلية لا يعني أن APK بُني أو أن التطبيق اختُبر على هاتف فعلي. يجب تنفيذ البناء والاختبار على بيئة Android مجهزة قبل إعلان الجاهزية للتثبيت.

### v2.8.1 — visual mathematics
The smart teacher can submit uploaded images and up to three rendered PDF pages to a configurable Groq vision model. Visual interpretation requires internet access and a vision-capable model; uncertain marks must be flagged rather than guessed.


### v2.8.3 — exam generation and visual-math quality
- Term 1, 2 and 3 practice-paper generation with exact grade/subject/term/language matching.
- Difficulty, duration and total-mark controls; separate student and teacher copies.
- Model answers, worked steps and a question-by-question marking rubric.
- Recent question IDs are remembered locally per grade/subject/term and excluded when enough exact-match alternatives exist.
- Visual mathematics review remains multimodal; uncertain diagram values must not be guessed.
- Papers remain platform practice material, not official Ministry examinations; teacher review is required.

### v2.8.3 — exam quality benchmark
Added a deterministic structural evaluator and source register; human review remains required for curriculum and solution correctness.
