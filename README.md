# SM éducation v2.9.7

## v2.9.7 — توسيع المولّد وإدارة المواضيع المحفوظة

- توحيد واجهة التوليد للسنوات الاثنتي عشرة والمواد المسجلة في بنك المنصة.
- دعم التمارين والفروض والاختبارات ونماذج BEM والبكالوريا وفق المرحلة.
- تحسين محاكاة بنية المواضيع المرجعية عبر الذكاء الاصطناعي عند توفره وقراءة ملف المرجع.
- إضافة أرشيف محلي للاحتفاظ بالمواضيع المولّدة واستعراضها وحذفها بصورة مستقلة عن بنك المكتبة.
- لا يُدّعى التوافق الرسمي مع التدرجات أو الشعب غير المتحقق منها؛ المحتوى التدريبي يحتاج مراجعة تربوية.
