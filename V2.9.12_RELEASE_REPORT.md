# SM EDUCATION v2.9.12 — Release report

## Scope

Improve the curriculum exam generator while preserving existing application and server routes.

## Implemented

- Replaced single-dimension cognitive-process selection with round-robin selection across topics and cognitive-process labels.
- Rejects duplicate question IDs, blank question text, and records without a usable answer or valid answer choice.
- Keeps exact grade, subject, term, and language matching. No cross-grade, cross-term, cross-language, or unverified stream substitution is introduced.
- Returns a machine-readable `quality_check` summary and topic/cognitive-process distributions with each generated paper.
- Displays the quality-gate result in the exam generator UI before the student/teacher version controls.
- Updated frontend, backend API, PWA cache, package metadata, and release wiring to v2.9.12.

## Validation

- `npm test`: PASS (exit code 0).
- Curriculum integrity audit: 1,581 exercise records; 105 grade/subject records; 0 exact duplicate questions; 0 errors; 0 warnings.
- Exam builder API tests: PASS, including duplicate/unanswerable-question filtering, point totals, quality metadata, and curriculum guardrails.
- PDF/OCR, document teacher, smart teacher, parent account/sync, adaptive learning, offline/PWA, repository safeguards, and release integrity regression tests: PASS.
- One repository-import test case is intentionally skipped because its sample URL belongs to a disallowed source host; the host allowlist guard behaves as expected.
