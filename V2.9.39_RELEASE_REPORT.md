# SM EDUCATION v2.9.39 — Direct textbook download

- One book at a time, on demand: download -> PDF check -> IndexedDB -> page-by-page index for the Smart Teacher.
- Safeguards: HTTPS only, host allow-list (config.js textbookHosts, empty by default), user confirmation, stop on 403/429, 80 MB cap, no bulk download.
- Catalogue schema (data/textbook-repository-index.json): books[] with id (A-Za-z0-9_.-), grade, subject, title, url, size_mb (optional). Grade and subject names must match the app (e.g. "الرابعة متوسط", "الرياضيات").
- Android uses CapacitorHttp (no CORS limit); in a normal browser the request may be blocked by CORS.
