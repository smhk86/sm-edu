# SM EDUCATION v2.9.40 — Textbook knowledge base for the Smart Teacher

## What changed
- New module `web/textbook-knowledge.js`: every textbook saved on the device (downloaded or imported) feeds ONE local search index (page-level BM25, Arabic-aware: diacritics, alef/ya/ta-marbuta variants, Arabic-Indic digits, light stemming). Nothing is uploaded.
- Smart Teacher chat: the question is searched across all books of the learner's grade (subject boosted); only the best pages (max ~9,000 characters, with book title + page number) go to the AI, and only if the learner enabled "use my books automatically" (remembered on the device). A "sources" line is shown under the answer.
- Offline answers: when the AI is unreachable, matching book pages are appended to the local answer (no consent needed, nothing leaves the device).
- Document review, exam and lesson prompt builders receive matching book pages when the toggle is on.
- Self-check panel ("قاعدة معرفة الكتب"): readiness checklist (catalogue, allowed host, confirmation, Android HTTP, Groq), retrieval self-test per saved book, and a connectivity test that fetches only the first KB of a catalogue book and verifies the %PDF signature.
- `tools/textbook_catalogue.js` (Termux): add / list / check / remove catalogue entries; `check` verifies each URL (HTTP status, %PDF signature, size, Range support, redirects). It never invents links; `--allow-host` is the only thing that edits `config.js`.

## Bugs fixed
- The book consent box only existed inside the books panel, so normal chat never used the books. The choice is now persistent and shared.
- `context()` without a query used to send up to 1.2 M characters of the selected book; it now sends nothing without a query and never more than the best pages.
- The AI prompt said "do not invent page numbers" while excerpts carried page numbers; it now says to cite only the page numbers shown.

## What is verified
- Unit tests (`tests/v2_9_40_textbook_knowledge_test.js`): tokenizer, retrieval, grade isolation, consent gate, size cap, legacy rows, index refresh, self-test, offline blocks, prompt builders, probe (simulated network), wiring.
- `tools/textbook_catalogue.js check` was run against a local HTTPS server (206 Range, HTML instead of PDF, 302, 429, 404).

## What is NOT verified (needs your phone)
- A real download from a real source: the catalogue ships empty and no source host is enabled, so nothing can be downloaded until you add entries for a source that allows it. Use `check` in Termux, then the in-app connectivity test, then a real download and the readiness/retrieval check.
- Scanned (image-only) books have no text layer and need OCR before they can be searched.
