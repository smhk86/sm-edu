# SM éducation v2.9.35 — Smart Teacher textbook knowledge library

## Delivered
- Added a grade-aware textbook access catalogue to the Smart Teacher page, using the active grade and subjects already defined by the platform.
- Added an in-app ONPS access viewer with an external fallback if the official site blocks iframe embedding.
- Added local PDF import. The app extracts selectable text from up to 18 pages / 18,000 characters and stores it in device-local IndexedDB.
- Added explicit per-request consent before the imported text is attached to the AI tutor request.
- Updated the direct Groq prompt to treat the excerpt as user-provided reference material, avoid invented page numbers, and avoid treating it as automatically official or error-free.
- Updated the API request schema with a bounded `book_context` field and versioned the release/service-worker cache as 2.9.35.

## Source and rights safeguards
- ONPS is used as the official discovery/reading entry point.
- No direct PDF URL is fabricated. The official catalogue row explicitly states when a direct file URL has not been verified.
- This build does not bypass ONPS activation, authentication, or digital-book protections.
- Imported PDFs remain on the device by default. Their extracted text is sent to the configured AI provider only after the user enables the consent checkbox.
- Image-only/scanned books are not falsely marked as indexed; OCR is a later enhancement.
