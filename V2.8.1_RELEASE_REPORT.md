# SM EDUCATION v2.8.1 — Visual mathematics and STEM analysis

## Focus
Turn uploaded exercise images and PDF pages into visual evidence that the smart teacher can use when correcting student work.

## Delivered
- Image uploads are resized in-browser and sent as multimodal image inputs to a configurable Groq vision model.
- Local PDF uploads render up to the first three pages as images using PDF.js, preserving geometry, graphs, labels, and spatial layout that text extraction can lose.
- The correction prompt requires a visual inventory before reasoning: visible labels, lengths, angles, symbols, graph axes, units, scales, and plotted points.
- The model must distinguish directly visible facts from inferred relationships, label confidence, and ask for a clearer crop instead of guessing.
- Existing OCR text extraction, DOCX reading, stepwise correction, privacy controls, and offline text features remain.
- Vision model is configurable in Groq settings; default: `qwen/qwen3.8-27b`.

## Limits and safety
- Visual analysis requires an internet connection and a valid Groq key plus an available vision-capable model.
- PDF visual input is limited to three pages per review to control payload size. Select/crop the relevant page when the exercise is later in the document.
- No visual model can guarantee exact recognition of faint handwriting, tiny labels, or ambiguous geometry marks. The response must flag uncertainty; teacher/student verification remains necessary.
- Offline mode remains text-only. No production Groq key or live vision call was used during automated tests. No APK build or physical Android-device test was performed.
